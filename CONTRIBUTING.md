# Contribuindo para Carsai LMS

Obrigado por considerar contribuir para o Carsai LMS! 🎉

## Como Contribuir

### Reportando Bugs

Antes de criar uma issue, verifique se ela já não existe.

Ao criar uma issue de bug, inclua:
- Versão do app
- Versão do Android
- Descrição detalhada
- Passos para reproduzir
- Screenshots (se aplicável)

### Sugerindo Melhorias

Issues de feature request são bem-vindas! Inclua:
- Descrição clara da funcionalidade
- Por que seria útil
- Exemplos de uso

### Pull Requests

1. Fork o repositório
2. Crie uma branch para sua feature
3. Faça suas alterações
4. Teste completamente
5. Commit com mensagens claras
6. Abra um Pull Request

### Padrões de Código

- Java 17
- Material Design 3
- Comentários em inglês no código
- Nomes de variáveis descritivos

### Commits

Use mensagens de commit claras:
```
feat: adiciona verificação de atualizações
fix: corrige upload de arquivos
docs: atualiza README
style: formata código
refactor: refatora WebViewClient
test: adiciona testes unitários
chore: atualiza dependências
```
